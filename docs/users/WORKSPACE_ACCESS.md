# Ambient 本机工作区远程入口

Ambient 已完成[接口适配](../developers/AMBIENT_WORKSPACE_HANDOFF_2026-10-01.md)；当前公网启用情况见[发布记录](../releases/AMBIENT_WORKSPACE_DEPLOYMENT_2026-10-01.md)。云门户可打开用户自己的 Ambient；Agent、App 数据、密钥和任务执行仍在用户电脑。完整工作区授权与普通 Agent Comm 对话授权分别确认。

1. 登录目标云账户，在工作区入口主动生成本机接入码。码五分钟后失效，只能使用一次。
2. 在自己的 Ambient 远程设置中填写公开 Gateway、门户地址和接入码，选择期限与权限并开始连接。`workspace.control` 可读写工作区并执行任务；附加 `workspace.manage` 才可管理 Provider、Coding Agent、Skill 和 capability。
3. 将 Ambient 返回的配对码在同一云账户领取。配对码同样五分钟有效，不能由其他账户领取。
4. 回原电脑核对账户、范围和期限并明确确认。生成接入码或云端领取都不代替本机确认。
5. 门户显示在线后打开工作区。打开链接只用一次，下次从门户生成新链接。浏览器会话最多一小时，不超过授权期限。

电脑需开机、联网并运行 Ambient。离线不取消本机已运行任务，恢复后读取原任务状态，不因回执丢失重复提交。接入码过期或响应丢失时按界面提示重新发起，不能重复自动创建。界面显示额度或暂时繁忙时等待再试。

门户或本机撤销会使远程请求与已有连接失效；已执行操作不能倒退。本机离线撤销先关闭本地通道，不能继续使用原许可。误领时不要在本机确认，撤销本次连接后重来。不同节点使用独立域名。默认与门户使用不同注册域名；临时子域名部署会要求浏览器重新登录一次。临时模式请使用现代浏览器，并通过地址栏或书签回到门户，直接从工作区点击门户链接会被拦截。

Gateway 不持久保存中转业务正文；TLS 入口运营者能够处理明文请求与响应。现有 Agent Comm 云工作台同步副本沿用独立机制。数据边界见[设计](../architecture/WORKSPACE_GATEWAY_PROPOSAL.md)。
