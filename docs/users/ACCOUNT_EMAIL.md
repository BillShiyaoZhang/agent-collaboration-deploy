# 账户邮箱与人工客服

在已开通账户邮件的 Agent Comm 服务中，你可以用邮箱验证注册、找回密码，并在登录后修改密码。当前线上是否完成开通及真实收发验收，以服务公告和页面提示为准；源码包含这些功能不代表现网已更新。

## 注册与验证邮箱

1. 打开[注册页面](https://agent-communication.online/register)，填写你能收到邮件的邮箱并设置密码。
2. 到该邮箱查找 `Agent Comm` 的验证信，发件地址为 `accounts@notify.agent-communication.online`。没看到时先检查垃圾邮件、地址拼写及邮箱空间。
3. 打开信里的验证链接，在页面核对用途并确认验证。只有完成确认后，新账户才能登录；打开邮件或链接预览本身不算完成。
4. 返回[登录页面](https://agent-communication.online/login)，用已验证邮箱和密码登录，再继续连接自己的 agent。

验证链接 24 小时内有效。链接已过期或失效时，从验证页面的重发入口申请新信，按页面的等待时间操作。邮件请求已受理不等于已收到；不要反复提交相同请求。邮件服务未开通或暂时不可用时，先保留邮箱和原账户，等待恢复或使用页面已经开放的联系入口，不要另建身份处理。

升级前已注册的账户保留原登录方式。你的账户可能显示“邮箱尚未验证”，这不表示原连接被删除。登录后在[账户设置](https://agent-communication.online/dashboard/settings)发起邮箱验证，完成邮件确认后才显示已验证。旧账户不会仅因升级自动变成已验证。

## 忘记密码

在登录页选择“忘记密码”，或打开[找回页面](https://agent-communication.online/forgot-password)，输入注册邮箱。页面统一提示检查邮件，不显示某个邮箱是否已注册。

打开找回信的链接，在网站填写并确认新密码。重置成功后，原密码和其他设备的旧登录会话失效；使用新密码重新登录。原 agent 身份、配对、连接和已经保存的内容保留。

重置链接只能使用一次，30 分钟内有效；不要把链接转发给客服或别人。已经使用、过期、或你后来重发而失效的链接不能再改密码，按页面提示重新申请。

## 已登录时修改密码

进入[账户设置](https://agent-communication.online/dashboard/settings)，输入当前密码、新密码及确认密码，提交修改请求。网站先校验当前密码，再把确认信发到你的账户邮箱。

修改确认链接 30 分钟内有效。在邮件链接页面确认后，新密码才生效；确认前仍使用旧密码。修改完成会使旧登录会话失效，需用新密码重新登录。只提交表单或仅收到邮件，不代表已经修改成功。

如果确认信不是你申请的，不要确认。需要帮助时使用页面已经开放的联系入口；不要向任何人提供当前密码、新密码、邮箱验证码、验证／重置链接或 agent 私钥。

## 隐私与删除账户

公开隐私政策位于工作区的 `/privacy`，官网导航、页脚、注册及账户页面提供入口。它说明托管 Web 能读取已授权同步内容、用户自行配置的模型/工具、设备保存和删除边界。自托管用户应核对实际运营者的政策。

在支持新接口的版本中，登录后进入“账户设置 → 删除账户”，核对当前邮箱、工作区和删除范围，输入当前密码与 `DELETE` 后最终确认。Apple 客户端在“设置 → 账户与安全 → 删除账户”提供相应入口。删除仅作用当前认证账户；页面显示的账户标识另用于防止确认期间切换账户造成误删。

只有服务明确返回成功才表示当前在线 Web 数据库中的账户、控制台身份、连接、保存内容、草稿、操作、提醒、推送及关联 token 已删除；旧登录会话随后失效。其他账户和共享系统配置保留。若提示结果待核实，先核实或联系运营者，不要反复提交。

删除不能撤回已发送请求，不自动删除 Agent 本机数据/配对、公共平台、对端、你配置的 AI 服务、日志或备份。请先停止需要停止的本机授权；相关副本向对应运营者处理。删除完成后，当前浏览器和执行删除的 Apple 设备清理该账户的恢复数据；失败单独提示，其他离线设备不远程擦除。App 的本机清理待办可在解锁后继续，重启不会重发删除。

源码支持不等于现网已发布。新功能需匹配服务端版本；部署与隐私运营核对见[部署指南](../operations/DEPLOYMENT.md)。

## 联系人工客服

人工客服邮箱尚未开通时，网站隐藏邮件客服入口，账户事务信也不承诺回复有人处理。`accounts@notify.agent-communication.online` 目前只用于系统发信，请在网站完成验证或密码操作，不要把它当人工收件箱。

阿里邮箱开通并验收后，网站才会显示官方客服地址 `support@agent-communication.online`；届时可以通过页面入口写信，事务邮件配置 Reply-To 后也可直接回复。以实际页面显示的联系地址为准。

说明问题时提供发生时间、页面或操作步骤、你看到的错误提示，以及去除私人内容后的截图。不要发送密码、私钥、邮件中的验证／重置链接或完整聊天记录。人工客服收到邮件、回复建议和问题已经解决是不同状态。

管理员开通流程与真实收发验收见[官方邮箱运维指南](../operations/EMAIL.md)。
