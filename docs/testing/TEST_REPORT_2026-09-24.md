## 已发现问题、修复与边界

1. **T13 线上仍失败。** [协议说明](../architecture/COMPLIANCE_GATEWAY.md)、[用户升级说明](../users/PRIVACY_MODE_UPGRADE.md)、[架构索引](../architecture/README.md)和[迁移指南](../operations/V2_MIGRATION.md)已在工作区修正为“服务端代码已部署、签名策略未启用、公开包仍为 r2”；公网前三页仍有过时文案，迁移指南状态不够准确。修复发布后必须再用公网 HTTPS 验证，不能以本地结构检查抵消线上失败。
2. **策略隔离的 ACK 与读取缺口。** [基线 E1 复现](../../agent-collaboration-web/build/web-managed-cert-matrix/8930cc09-a845-4aba-9fbb-5c47b098db8c/result.json)显示托管证书撤销后，原响应已不可读，持有收件私钥仍能直接 ACK 并标为已读；代码审查发现旧策略 v2 行同样可被 ACK，最老 500 条隔离 v1 行还会遮挡后面的有效消息。这是交付状态和可用性错误，不是正文泄露。本地 Platform 修复让 ACK 只确认当前可交付行，并以有界分页越过旧隔离行；[Go/race 与 1000+1 专项](../../build/test-runs/20260924-managed-cert-fix/targeted-results.json)、[修复版真实 E1 Web 往返](../../agent-collaboration-web/build/web-managed-cert-matrix/3a9bb636-a0d0-4071-9b41-e55998efa9cf/result.json)、[修复版 E2-V HTTPS](../../build/test-runs/20260924-sdk-platform-subagent/e2v-ackfix/results/e2v-ackfix-summary.json)通过。修复尚未提交或部署到生产；隔离 E2-V 已清理，生产镜像仍是旧行为。
3. **迁移时的队列容量边界。** 旧隔离 v1/v2 未读行仍与新流量共用每收件人配额；默认 500 条满额时，新受管控制消息和 v2 消息会收到 429。这是有界磁盘背压，不能靠暗中 ACK 或自动清空旧行解除。本地[迁移指南](../operations/V2_MIGRATION.md)已加入切换前盘点、必要时有界扩容和监控。10 万条且来自大量不同发送者的极端隔离队列未压测，读取仍可能在 10 秒超时后从头重试；本轮 1000 条样本不能覆盖该上限。
4. **Web 自动无障碍回归发现真实缺陷。** 官网跳转正文链接焦点顺序、登录/注册 320px 放大布局、工作台/提醒中心溢出和提醒对比度已在 Web 子模块修复。浏览器无障碍检查 30/30 与 Web 单测/构建通过；这些改动尚未提交或部署到线上。
5. **测试脚本假设与环境差异。** E2-L 首次 MQ 合成行不是合法 protobuf，修正 fixture 后同一管理检查通过；备份脚本初用宿主 Python 3.6 不具备的 `sqlite3.Connection.backup`，改用 SQLite CLI 在线 `.backup`；首次恢复未关闭句柄，修正后完整恢复通过。三处属于测试工具/fixture 问题，保留首次失败，不归咎于产品。
6. **Web 工作台韧性测试的旧断言已修正。** 首跑脚本期望断线状态为 `offline`，现行策略不可得时正确的失败关闭状态是 `policy_unavailable`；修正测试断言后，[持久副本/进程重启/恢复三项检查](../../agent-collaboration-web/build/workspace-sync-preview/resilience-result.json)通过。[首次失败日志](../../agent-collaboration-web/build/test-evidence-20260924/index.json)保留为测试版本差异，不算产品通过证据。
7. **T12 首次首装夹具路径失败。** 本地临时 Web 与 Platform 分两个端口，公开 r2 onboarding 默认同源入口，故首轮在注册阶段停止；第二套全新 venv/profile 使用本机统一 origin 代理后，真实安装、网页合成 claim、连接和 capabilities 均通过。候选 v2 首轮披露探针误带 Web `Origin`，helper 正确返回 403；同一身份去除错误请求头后，签名 private 披露与密钥/邮箱保持均通过。没有复制真实 Hermes 身份或模型密钥；这不证明真实模型回答。
8. **发布边界。** 当前生产 `/api/v2/policy` 为 404，表示签名 v2 策略未启用；公开包是 r2。E1 的合成授权、Web 合成账户确认及候选 v2 ZIP 均不能写成真实用户已同意或公开 v2 已发布。
