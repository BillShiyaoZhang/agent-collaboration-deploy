# 2026-09-26 Web 聊天与合作工作流

本次按[聊天与合作设计](../design/WEB_CHAT_AND_COLLABORATION.md)交付 P0/P1：人可以直接和自己的 agent 对话，通过联系人和目标表单发起合作，在原对话与合作列表判断进展并完成明确的审批。

**状态：实现与本地验收阶段，尚未切换生产。** 固定提交、生产镜像、正式 SDK 资产和云端验收将在实际完成后补充。本记录不代表已安装 agent 自动升级。

## 交付范围

- 聊天、合作、联系人、我的四个入口；单 agent 直接进入聊天，多 agent 从聊天列表选择。
- 格式化回复、复制与引用、会话标题、归档、保存范围内的搜索、草稿及滚动位置；切换会话先保存旧草稿，失败保留原界面。
- 目标、成功条件、联系人、时间范围、资源和预算的合作表单；沿用准备事项、范围审批、邀请、接收回执和独立有限 worker 授权。
- 合作卡显示目标、状态、参与方、最后变化、授权范围与下一步。仅有邀请发出、传输回执或 agreement 尚未同步时不能显示业务完成。
- 真实来源关联原对话与相关事项；自然语言中的 ID 不构成可信关联，也不产生任何额外授权。
- 普通聊天完成、失败和中断的持久提醒；查看原对话才推进已读，查看事项页不消除聊天结果提醒。
- 服务端持久操作记录和稳定请求 ID；未知写入结果只核对原操作，过期且可能重复的写入不能通过通用“重新提交”生成新请求。
- SDK runtime 0.1.8 / Hermes connector 1.5.10（v0.9.3）的可信来源、历史范围和聊天结果提醒支持。旧安装继续按已声明的能力工作。

P2 的流式回复、附件、日历执行和更完整的协作会话留作后续实现；当前有限 worker 的暂停、关闭及授权有效期按实际运行时语义显示。暂停本机 worker 不表示对方已停止。平台策略、用户身份和配对继续沿用现行配置。
