## 交付范围

- 聊天、合作、联系人、我四个入口；单 agent 直接进入聊天，多 agent 从聊天列表选择。
- 格式化回复、复制与引用、会话标题、归档、保存范围内的搜索、草稿及滚动位置；切换会话先保存旧草稿，失败保留原界面。
- 目标、成功条件、联系人、时间范围、资源和预算的合作表单；准备事项、范围审批、邀请、接收回执和独立有限 worker 授权形成完整路径。
- 合作卡显示目标、状态、参与方、最后变化、授权范围与下一步。邀请发出、传输回执或 agreement 尚未同步时不能显示业务完成。
- 可信来源关联原对话与相关事项；从结果继续讨论时保留已有草稿并追加上下文，不自动发送。自然语言中的 ID 不构成可信关联，也不产生额外授权。
- 普通聊天完成、失败和中断的持久提醒；查看原对话才推进已读，查看事项页不消除聊天结果提醒。
- 服务端持久操作记录和稳定请求 ID；未知写入结果核对原操作，过期且可能重复的写入不能通过通用“重新提交”生成新请求。
- 联系人申请、接受、拒绝、重申请与精确消息已读；填写下一位联系人时，旧成功反馈不会被轮询重新放回表单。
- SDK runtime 0.1.8 / Hermes connector 1.5.10（v0.9.3）支持可信来源、历史范围和聊天结果提醒。旧安装继续按已声明的能力工作；需要新宿主能力的功能须升级对应 agent 的 SDK/connector。

P2 的流式回复、附件、日历执行和更完整的协作会话留作后续实现。有限 worker 的暂停、关闭及授权有效期按实际运行时语义显示；暂停本机 worker 不表示对方已停止。平台策略、用户身份和配对沿用现行配置。
