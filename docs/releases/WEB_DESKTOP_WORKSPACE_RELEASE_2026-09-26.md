## 交付与管理语义

- “聊天”改为“我的 agents”，默认直接选择已连接 agent 并展示聊天框。电脑采用 176px 导航、264px agent/主题列表和剩余宽度的聊天区；消息独立滚动，输入区固定。合作、联系人、我、连接设置分别呈现；旧混合工作台地址保留原参数并兼容跳转。
- agent 可改名、打开连接设置和删除连接；会话可改名、归档、删除和恢复；联系人与已确认终态的合作可删除和恢复网页显示。手机采用列表抽屉与四项底部导航；未覆盖实体手机。
- **删除连接**会删除该账户连接及其关联 Web 副本，没有连接回收站；以后重新接入只能读取 agent 仍能提供的记录。服务端拦截运行中/已提交的聊天回合、未知发送、未确认中断及 sending/uncertain 业务写入。
- **删除会话、联系人或合作网页记录**采用可恢复的账户状态，后续同步不会自动重新显示。会话处理中不能删除；联系人删除还检查待处理好友请求与相关审批；合作删除还检查所有关联合作的终态证据与相关审批。任务与合作别名使用同一删除状态。
- Agent 本机身份、配对、业务事实保留；删除网页记录或连接不会停止远程执行。恢复记录和草稿不自动发送消息。账户、同源与确切对象校验在服务端执行。

已修复旧读取恢复已删连接/记录、跨设备已删对话恢复草稿、快速切换 agent 错选空主题及详情与总览删除状态不同步。确认删除/恢复事件立即合并父总览，并使旧 GET 失效；未发送的本地草稿保留。
