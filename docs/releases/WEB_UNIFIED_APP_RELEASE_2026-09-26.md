## 应用与部署变化

- `/` 与 `/docs/` 改由 Next.js 页面提供，工作台保留原登录与授权流程；公开页面和工作台使用应用内导航。
- 文档阅读器保留 `?path=` 分享链接及四仓公开 Markdown 原文入口。Next 独立运行时提供原文只读路由；生产 nginx 继续按明确允许的路径提供原文，非公开文档返回 404。
- nginx 的 `/docs` 跳转到 `/docs/`，`/docs/` 转发至 Next 的 `/docs`，避免末尾斜杠重定向循环。历史文档跳转、安装说明与下载入口保留。
- Web 镜像包含应用页面、静态资源和 Web 自身文档；完整四仓文档由根 Compose 只读挂载。nginx 与 Web 容器实际以 `nginx`、`nextjs` 用户读取四仓样本文档通过。
- 旧 `site/index.html`、`site/docs/index.html` 保留为历史参考，当前页面修改入口是 Web `src/app`。本次移除 nginx 的 `/srv/site` 静态页面挂载。

现行运维步骤、文档权限和回滚要求见[部署指南](../operations/DEPLOYMENT.md)。
