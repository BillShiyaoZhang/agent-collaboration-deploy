# 产品决策

本页保留早期探索和浏览器 Demo 中仍适用于现行产品的决定。Demo 实现和运行说明已经退役，原文可在 Git 历史查阅；未实施的探索不是当前功能承诺。具体代码边界以 [当前架构](OVERVIEW.md) 为准。

## 人物、联系人和端点分别表示

宿主记忆可以提供人物别名和候选线索；本地协作状态保存稳定联系人及经确认的 URN 绑定。公钥证明一个网络端点的身份；端点是否代表现实人物，需要可信渠道或主人确认。对端自报姓名、替他人介绍账号、声称更换密钥都先作为待核实声明，不能直接改变可信绑定。

## 围绕一件事表达授权

授权记录明确能力、收件人、参与人、资料、时间、数量和有效期限。范围内的结构化动作可以连续执行；范围变化需要对应的追加决定。只允许某人参会，不等于允许向其发送原先只给另一人的资料。新增一次固定动作的许可不自动成为长期授权。

自然语言帮助表达意图；当前 Hermes 的权限执行依赖原生问题卡、真实主体/会话/回合及固定问题版本。模型参数、远端文字和主聊天中的裸“可以”不能替代这个已实现的确认渠道。

## 私人记忆提供有界结果

宿主继续管理原有记忆。适配器按查询范围返回有限结果和带来源、版本的资料快照，避免将完整日历、图谱或私人背景同步给对端。资料存在本地不等于获准披露；对方收到明文后，用途标签和到期时间也不能保证对方遗忘或不转发。

## 动作、状态与恢复由程序管理

Skill 说明协作方式，持久状态保存事实，受控工具负责执行检查。恢复读取当前事项和授权状态，不重放旧文本来重新取得授权；重试保留稳定请求、操作和消息 ID。进程中断且副作用不确定的任务需要核实原结果，不自动重新执行。

## 分别证明送达、接受和执行

helper 接受消息、云 MQ 保存消息、对方接收、各方接受同版方案及日历写入是不同事实。界面和日志必须区分这些状态；模型回复也不能替代协议状态或外部工具的执行凭据。当前会议能力交换方案消息，不写入日历。

## Agent 授权与工作台副本分别管理

Agent 持有协作事实和访问授权。Web 在账户范围保存已认证读取内容的加密副本并主动同步，便于刷新、换设备及离线查看。添加连接不授予访问权；离线副本不证明当前授权仍有效。撤销阻止后续访问，不能召回已经同步的内容；Web 服务会解密处理获准内容，用户需要信任这个托管端点。
