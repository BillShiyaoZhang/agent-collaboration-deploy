审核版本同时核消息 ID、发送者、类型、完整正文与摘要。只有已确认的本机派生 `trust`、`unknown_sender` 和服务端投影字段按固定规则排除，其他语义字段仍参与摘要。Native 完整预览、网站具体审核行及其一次性预览令牌必须分别对应同一目标；旧的已批准版本不替新版本做决定，拒绝版本不会因另一个版本批准而解封。
